# 如何更新 Ensembler

本页讲的是更新 **Ensembler 本身** —— 也就是这个应用。（关于让
Sonarr、Plex 等*服务*保持最新，请参阅 **管理服务 →
让服务保持最新**。）

## 你怎么知道有更新

Ensembler 会不时检查是否已发布更新的版本，并在有新版本可用时
在仪表盘上显示一条小提示。你也可以随时在
**设置 → 常规 → 检查更新** 中检查。

Ensembler 绝不会自行安装新版本 —— 更新只是一个快捷的手动步骤，
而且在每个平台上思路都一样：**下载最新版本并打开它**。
你的服务和设置完全不受影响。

## 更新

1. 打开 **[发布页面](https://github.com/garethhallnz/ensembler/releases)**
   （更新提示会直接链接到那里）。
2. 下载适合你系统的文件，然后覆盖安装到当前的副本上：

   - **macOS** —— 下载 `.dmg`，打开它，把 **Ensembler** 拖入你的
     **应用程序** 文件夹，替换旧版本。首次打开新版本时，
     右键点击（或按住 Control 点击）该应用并选择 **打开**。
   - **Windows** —— 下载 `.exe` 并运行它。它会覆盖你现有的
     版本。如果 Windows 显示 “Windows protected your PC” 界面，请点击
     **More info → Run anyway**。
   - **Linux** —— 下载新的 `.AppImage` 并替换旧的。你可能
     需要重新将其标记为可执行（右键 → **属性 →
     权限**，或在终端中执行 `chmod +x`）。

3. 打开 Ensembler。就这样 —— 整个过程中你的服务持续运行，
   所有设置也都保持你上次离开时的样子。

## 关闭提示

如果你不想看到更新提示，可关闭 **设置 → 常规 → 更新通知**。
你仍然可以随时使用 **检查更新** 按钮手动检查。

> **为什么更新是手动的：** 这让 Ensembler 在 macOS、Windows 和 Linux
> 上保持简单和一致，也意味着这个应用绝不会在你背后擅自改动自己。
> 更新绝不会影响你的媒体文件。
