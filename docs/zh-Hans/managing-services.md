# 管理你的服务

一切都在**仪表盘**上进行。每个服务都有一张卡片，显示它的
状态以及你可以采取的操作。

## 服务卡片

- 一个彩色的**状态圆点**让你一眼看清当前状态：
  - **绿色 —— 运行中**
  - **灰色 —— 已停止**
  - **琥珀色 —— 需要设置**或**需要关注**
- **Open** 会**在 Ensembler 内部以标签页的形式**打开该服务 —— 无需单独的浏览器，
  也没有 "Not Secure" 警告。顶部有一个栏可让你在
  **Dashboard** 与任意已打开的服务之间切换，并通过标签页的 **✕** 关闭它。它还带有
  针对当前服务的**重新加载**和**在浏览器中打开**按钮。
- 每张运行中的卡片上会显示一个小小的**版本号**。**🔒 锁**表示该服务
  被固定在某个特定版本；**↻** 标记表示它跟踪最新版本。
  当有可用更新时，它会变为琥珀色。
- **⋯ 菜单**收纳了其余操作：**Open in browser**、**Start / Stop**、
  **Restart**、**View logs**、**Check for updates** 和 **Configure**。

当一个服务正在启动或停止时，状态会短暂显示
"Starting…/Stopping…"，让你知道有事情正在进行。

## 添加和移除服务

- **Add Service**（位于 Services 区域顶部）让你添加任何在设置时
  没有选择的项目。
- 要移除某个服务，打开它的 **⋯ 菜单 → Configure**。

## 让服务保持最新

- Ensembler 会在后台悄悄检查，因此可用更新会自行出现。你也可以点击 **Check for updates**（位于 Services 区域
  顶部）立即检查全部，或通过某个服务的
  **⋯ 菜单 → Check for updates** 检查单个服务（结果会显示在卡片上）。
- 当有可用更新时，Services 标题栏会显示更新数量，并提供一个
  **Update all** 按钮一次性应用它们。若只想更新一个，点击
  其卡片上的 **Update available — update now**。你的设置会被保留。
- **固定版本。** 默认情况下每个服务都会跟踪最新版本。要把
  某个服务保持在特定版本，打开 **⋯ 菜单 → Configure** 并从
  **Version** 下拉菜单中选择。被固定的服务会显示 🔒 并停止提供更新。
- **自动更新。** 开启 **Settings → Updates → Install updates
  automatically**，让 Ensembler 在后台应用可用更新。
  它默认关闭，因此主动权始终在你手中。

## 设置

打开 **Settings**（右上角）可访问全应用范围的选项：

- **Appearance** —— Light、Dark 或 System（跟随你的操作系统）。
- **General** —— 当你关闭窗口时，把 Ensembler 保留在菜单栏 / 系统托盘中
  （默认开启），这样它触手可及。无论哪种方式，你的服务都会保持运行；
  使用托盘菜单中的 **Quit** 可完全退出。
- **Updates** —— 为你的服务开启后台自动更新（默认
  关闭）。
- **Environment** —— 时区，以及用于文件权限的用户/组 ID。
- **Danger zone → Reset everything** —— 停止并移除所有服务及其
  设置，让 Ensembler 恢复到全新安装状态。**你的媒体文件绝不会
  被触碰** —— 仅移除服务及其配置。

## 你的设置存放在哪里

Ensembler 把它的配置存放在一个隐藏的、每用户独立的文件夹中（已为你
托管 —— 你应该不需要去编辑它）：

- **macOS：** `~/Library/Application Support/Ensembler`
- **Windows：** `%APPDATA%\Ensembler`
- **Linux：** `~/.config/Ensembler`

你的**媒体文件**（电视剧、电影、下载）存放在你在设置时选择的
任意位置，与此相互独立。

## 诊断

在仪表盘底部，**Diagnostics** 面板（默认折叠）
显示技术状态 —— Docker 是否在运行、有多少服务已启动，
等等。你通常不需要它，但在排查问题时很方便。
