# 什么是 Ensembler？

Ensembler 为你搭建并运行一套**家庭媒体中心** —— 广受欢迎的
"*arr" 套件（Sonarr、Radarr、Prowlarr 及其伙伴）外加一个媒体服务器，比如
Plex 或 Jellyfin —— 而你无需了解 Docker、YAML 或命令行。

你选择想要的服务，Ensembler 会安装它们、启动它们、把它们相互连接起来，
并为你提供一个统一的仪表盘来管理一切。

## 工作原理

在底层，每个服务都运行在各自的 **Docker 容器**中。Ensembler 会
生成 Docker 配置、启动容器，并把它们相互连接，让它们作为一个整体协同工作。你完全
不必去碰任何配置文件。

典型的流程是：

1. **设置向导** —— 选择你的服务，把 Ensembler 指向你的媒体
   文件夹，然后点击 **Apply**。端口会为你检查好，如果某个默认端口已被占用，也会
   自动选取空闲的端口。
2. **自动连接** —— Sonarr 和 Radarr 会获得各自的下载客户端和
   文件夹，Prowlarr 会与它们关联，媒体服务器会收到导入通知，
   等等。你可以看着每一步逐一完成。
3. **仪表盘** —— 从此之后你在一个地方管理一切：打开某个
   服务、启动/停止它、检查更新，或添加更多服务。

## 各个服务的作用

| 服务 | 角色 |
|---|---|
| **Sonarr** | 管理你的电视剧 |
| **Radarr** | 管理你的电影 |
| **Bazarr** | 为 Sonarr/Radarr 管理字幕 |
| **Plex / Jellyfin / Emby** | 将你的媒体串流到你的设备 |
| **Transmission / Deluge** | 下载客户端 |
| **Prowlarr / Jackett** | 管理你的服务搜索内容的来源 |
| **Overseerr** | 请求并发现媒体 |

## Ensembler 会做什么 —— 以及不会做什么

Ensembler **把你的各个服务连接在一起**。它**不会**选择、请求
或下载任何内容，也**不会**为你配置索引器或 tracker。你自己选择内容来源，
并对如何使用它们负责。
