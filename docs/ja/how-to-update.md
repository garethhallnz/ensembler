# Ensembler のアップデート方法

このページは **Ensembler 本体** — アプリのアップデートについて説明します。
（Sonarr や Plex などの *サービス* を最新に保つ方法については、**サービスの管理 →
サービスを最新に保つ** をご覧ください。）

## アップデートがあることの確認方法

Ensembler は新しいバージョンがリリースされているかどうかを随時確認し、利用可能な
場合はダッシュボードに小さな通知を表示します。**設定 → 一般 → アップデートを確認**
からいつでも確認することもできます。

Ensembler が自動的に新しいバージョンをインストールすることはありません。
アップデートは手早くできる手動の操作で、どのプラットフォームでも考え方は同じです:
**最新バージョンをダウンロードして開く** だけです。サービスと設定にはまったく
手が加えられません。

## アップデートの手順

1. **[リリースページ](https://github.com/garethhallnz/ensembler/releases)** を
   開きます（アップデート通知から直接リンクされています）。
2. お使いのシステム向けのファイルをダウンロードし、現在使用中のものに上書きして
   インストールします:

   - **macOS** — `.dmg` をダウンロードして開き、**Ensembler** を
     **アプリケーション** フォルダにドラッグして、古いものを置き換えます。
     新しいバージョンを初めて開くときは、アプリを右クリック（または
     Control キーを押しながらクリック）して **開く** を選択します。
   - **Windows** — `.exe` をダウンロードして実行します。既存のバージョンに
     上書きインストールされます。Windows に「Windows によって PC が保護されました」
     という画面が表示された場合は、**詳細情報 → 実行** をクリックします。
   - **Linux** — 新しい `.AppImage` をダウンロードし、古いものと置き換えます。
     再度実行可能にする必要がある場合があります（右クリック → **プロパティ →
     アクセス権**、またはターミナルで `chmod +x`）。

3. Ensembler を開きます。以上です。処理中もサービスは実行を継続し、設定はすべて
   残したとおりのままです。

## 通知をオフにする

アップデート通知を表示したくない場合は、**設定 → 一般 → アップデート通知** を
オフにします。**アップデートを確認** ボタンで、好きなときに手動で確認することは
引き続き可能です。

> **アップデートが手動である理由:** macOS、Windows、Linux のいずれでも Ensembler を
> シンプルで一貫したものに保ち、アプリが知らないうちに自分自身を変更することが
> ないようにするためです。メディアファイルがアップデートの影響を受けることは
> 決してありません。
