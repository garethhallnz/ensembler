# はじめに

## 必要なもの

Ensembler はサービスを Docker で実行するため、インストールされ実行されている
**コンテナランタイム** が必要です。`docker` と `docker compose` コマンドを
提供するものです。

- **推奨（最も簡単）:**
  [Docker Desktop](https://www.docker.com/products/docker-desktop/) — macOS、
  Windows、Linux 向けのワンクリックインストールです。お持ちでない場合、
  Ensembler が初回起動時に案内します。
- **すでに別のものをお使いですか？** Docker 互換のランタイムであれば同じように
  動作します。例えば **OrbStack**（macOS）、**Podman**、**Rancher Desktop**、
  **colima**、Linux 上の **Docker Engine** などです。`docker` と
  `docker compose` が動作する限り、Ensembler はそれらを使用します。

このアプリを使うのに Node.js、ターミナル、開発者ツールは **不要** です。

## 初回起動

Ensembler を初めて開くと、Docker が実行されているか確認します。Docker が
インストールされていない、または起動していない場合は、それを解決するための
手順が表示されます。Docker Desktop を起動し、実行中と表示されるまで待つと、
Ensembler が続行します。

## セットアップウィザード

### 1. サービスを選択
完全なメディアセンター向けに、推奨サービスがあらかじめ選択されています。
一部のカテゴリ（ダウンロードクライアント、インデクサー管理、リクエスト）では
1つの選択肢のみを選べます。その他（**メディアサーバー** と **メディア管理**）
では複数を選べます（例えば Plex と Jellyfin の両方を実行できます）。

### 2. フォルダを設定
**TV 番組**、**映画**、**ダウンロード** の保存場所を Ensembler に指定します。
これらはあなた自身のフォルダです。ライブラリに十分な空き容量のある場所を
選んでください。ポートは自動的にチェックされ、デフォルトのポートがすでに
使用中の場合、Ensembler が空いているポートをそっと選びます。

### 3. 適用
Ensembler が設定を生成し、サービスを起動し、それらを相互に接続します。
各ステップが完了する様子が表示されます。

## セットアップの仕上げ

いくつかの手順はあなたにしか行えません。ダッシュボードの
**「セットアップを完了」** リストでそれらを促します:

- **Prowlarr にインデクサーを追加** — Sonarr と Radarr がコンテンツを
  検索できるようにします。ソースはあなた自身が選びます。Ensembler が
  これらを選ぶことは決してありません。
- **Plex にサインイン** — その後 Ensembler が TV と映画のライブラリを
  自動的に作成します。
- **Overseerr を完了** — Plex でサインインし、他のサービスを発見します。

各プロンプトには、適切な場所へ直接移動できる **開く** リンクがあります。

**Jellyfin または Emby をお使いですか？** これらはリストにありません。
Ensembler はコンテナを実行しますが、それぞれが独自の初回起動を管理します。
ダッシュボードから開き、それぞれの Web インターフェースでセットアップを
完了してください（管理者アカウントを作成し、ライブラリを追加します）。

これらが完了すれば、準備完了です。
