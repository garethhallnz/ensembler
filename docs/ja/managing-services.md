# サービスの管理

すべては **ダッシュボード** で行います。各サービスにはカードがあり、その状態と
実行できる操作が表示されます。

## サービスカード

- 色付きの **ステータスドット** で状態がひと目でわかります:
  - **緑 — 実行中**
  - **グレー — 停止**
  - **アンバー — セットアップが必要** または **対応が必要**
- **開く** は、サービスを **Ensembler 内のタブとして** 開きます。別のブラウザは
  不要で、「Not Secure」の警告もありません。上部のバーで **ダッシュボード** と
  開いているサービスを切り替えたり、**✕** でタブを閉じたりできます。現在の
  サービス用の **再読み込み** ボタンと **ブラウザで開く** ボタンもあります。
- 実行中の各カードには小さな **バージョン** が表示されます。**🔒 ロック** は
  サービスが特定のバージョンに固定されていることを意味し、**↻** マーカーは
  最新を追従していることを意味します。アップデートが利用可能になると
  アンバー色になります。
- **⋯ メニュー** にはその他の操作があります: **ブラウザで開く**、
  **開始 / 停止**、**再起動**、**ログを表示**、**アップデートを確認**、**設定**。

サービスの開始中または停止中は、ステータスに簡単な
「開始中…/停止中…」が表示され、何かが起きていることがわかります。

## サービスの追加と削除

- **サービスを追加**（サービスセクションの上部）で、セットアップ時に選ばなかった
  ものを追加できます。見つけやすいようカテゴリごとにまとめられています。
- サービスを削除するには、その **⋯ メニュー → 設定** を開きます。

ここでもダッシュボードでも、サービスはカテゴリごとにまとめられています
（メディアサーバー、メディア管理、ダウンロードクライアントなど）。

## サービスを最新に保つ

- Ensembler はバックグラウンドで静かに確認するため、利用可能なアップデートは
  自動的に表示されます。**アップデートを確認**（サービスセクションの上部）を
  クリックしてすべてを今すぐ確認したり、**⋯ メニュー → アップデートを確認** で
  1つのサービスを確認したりすることもできます（結果はカードに表示されます）。
- アップデートが利用可能な場合、サービスのヘッダーにその件数が表示され、
  **すべてアップデート** ボタンで一度に適用できます。1つだけアップデートするには、
  そのカードの **アップデートあり — 今すぐアップデート** をクリックします。
  設定は保持されます。
- **バージョンを固定。** デフォルトでは各サービスは最新バージョンを追従します。
  特定のバージョンに保持するには、**⋯ メニュー → 設定** を開き、**バージョン**
  ドロップダウンから選択します。固定されたサービスには 🔒 が表示され、
  アップデートの提示が停止します。
- **自動アップデート。** **設定 → 一般 → アップデートを自動的にインストールする**
  をオンにすると、Ensembler が利用可能なアップデートをバックグラウンドで
  適用します。デフォルトはオフなので、あなたが制御を維持できます。

## 設定

**設定**（右上）を開くと、アプリ全体のオプションがセクションごとに整理されています:

- **外観** — テーマ（ライト、ダーク、システム）と言語。
- **一般** — ウィンドウを閉じたときに Ensembler をメニューバー / システムトレイに
  残す（デフォルトはオン。どちらの場合もサービスは実行を継続します。完全に
  終了するにはトレイメニューの **終了** を使います）、サービスのアップデートを
  自動的にインストールする（デフォルトはオフ）、タイムゾーン。
- **詳細設定** — 通常は必要のない技術的な詳細: 診断（Docker が実行中か、
  いくつのサービスが稼働中か）、空きディスクとメモリ、ファイル権限に使用される
  ユーザー ID / グループ ID。
- **リセット → すべてリセット** — すべてのサービスとその設定を停止・削除し、
  Ensembler を新規インストールの状態に戻します。**メディアファイルには一切
  触れません** — サービスとその設定のみが削除されます。

## 設定の保存場所

Ensembler は、ユーザーごとの隠しフォルダに設定を保存します（自動的に管理され、
編集する必要はありません）:

- **macOS:** `~/Library/Application Support/Ensembler`
- **Windows:** `%APPDATA%\Ensembler`
- **Linux:** `~/.config/Ensembler`

**メディアファイル**（TV、映画、ダウンロード）は、セットアップ時に選んだ場所に
保存され、これとは別に管理されます。

## 診断

技術的な状態（Docker が実行中か、いくつのサービスが稼働中か、空きディスクと
メモリはどれくらいか）は **設定 → 詳細設定** にあります。通常は必要ありませんが、
トラブルシューティングのときに便利です。
