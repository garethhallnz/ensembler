# Ensembler とは？

Ensembler は、Docker、YAML、コマンドラインの知識がなくても、あなたのために
**ホームメディアセンター** をセットアップして実行します。人気の
「*arr」スタック（Sonarr、Radarr、Prowlarr など）に加え、Plex や Jellyfin の
ようなメディアサーバーを組み合わせます。

必要なサービスを選ぶだけで、Ensembler がそれらをインストールし、起動し、
相互に連携させ、すべてを管理できる単一のダッシュボードを提供します。

## 仕組み

内部では、各サービスがそれぞれ独自の **Docker コンテナ** で実行されます。
Ensembler は Docker の設定を生成し、コンテナを起動し、それらを相互に接続して
1つのシステムとして動作させます。設定ファイルに触れる必要は一切ありません。

一般的な流れは次のとおりです:

1. **セットアップウィザード** — サービスを選び、Ensembler にメディアフォルダを
   指定し、**適用** をクリックします。ポートは自動的にチェックされ、デフォルトが
   使用中の場合は空いているポートが自動的に選ばれます。
2. **自動連携** — Sonarr と Radarr にダウンロードクライアントとフォルダが
   設定され、Prowlarr がそれらにリンクし、サインインすると Plex がインポート
   通知を受け取る、といった具合です。各ステップが完了する様子を見ることができます。
3. **ダッシュボード** — 以降はすべてを1か所から管理します。サービスを開く、
   開始/停止する、アップデートを確認する、さらにサービスを追加する、などです。

## 各サービスの役割

| サービス | 役割 |
|---|---|
| **Sonarr** | TV 番組を管理 |
| **Radarr** | 映画を管理 |
| **Bazarr** | Sonarr/Radarr の字幕を管理 |
| **Plex / Jellyfin / Emby** | メディアをデバイスにストリーミング |
| **Transmission / Deluge** | ダウンロードクライアント |
| **Prowlarr / Jackett** | サービスがコンテンツを検索する場所を管理 |
| **Overseerr** | メディアのリクエストと発見 |

## Ensembler ができること、できないこと

Ensembler は **サービスを相互に接続します**。コンテンツの選択、リクエスト、
ダウンロードは **行いません**。また、インデクサーやトラッカーの設定も
**行いません**。ソースはあなた自身が選び、その利用方法についてはあなたが
責任を負います。
