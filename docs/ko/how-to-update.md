# Ensembler 업데이트 방법

이 페이지는 **Ensembler 자체** — 즉 앱을 업데이트하는 방법을 다룹니다. (Sonarr나
Plex 같은 *서비스*를 최신 상태로 유지하는 방법은 **서비스 관리 → 서비스 최신 상태
유지**를 참고하세요.)

## 업데이트가 있는지 알아보는 방법

Ensembler는 새 버전이 출시되었는지 이따금 확인하며, 사용 가능한 버전이 있으면
대시보드에 작은 알림을 표시합니다. 언제든지 **설정 → 일반 → 업데이트 확인**에서
직접 확인할 수도 있습니다.

Ensembler는 새 버전을 스스로 설치하지 않습니다 — 업데이트는 간단한 수동 단계이며,
모든 플랫폼에서 방식은 같습니다: **최신 버전을 다운로드하여 여는 것**입니다.
서비스와 설정은 전혀 건드리지 않습니다.

## 업데이트하기

1. **[출시 페이지](https://github.com/garethhallnz/ensembler/releases)**를
   여세요(업데이트 알림이 바로 여기로 연결됩니다).
2. 사용하는 시스템에 맞는 파일을 다운로드한 다음, 현재 사본 위에 설치하세요:

   - **macOS** — `.dmg`를 다운로드하여 열고, **Ensembler**를 **응용 프로그램**
     폴더로 끌어다 놓아 기존 것을 대체하세요. 새 버전을 처음 열 때는 앱을
     마우스 오른쪽 버튼으로 클릭(또는 Control-클릭)하고 **열기**를 선택하세요.
   - **Windows** — `.exe`를 다운로드하여 실행하세요. 기존 버전 위에 설치됩니다.
     Windows에 "Windows에서 PC를 보호했습니다" 화면이 표시되면
     **추가 정보 → 실행**을 클릭하세요.
   - **Linux** — 새 `.AppImage`를 다운로드하여 기존 것을 대체하세요. 다시 실행
     권한을 부여해야 할 수 있습니다(마우스 오른쪽 버튼 클릭 → **속성 → 권한**,
     또는 터미널에서 `chmod +x`).

3. Ensembler를 여세요. 이것으로 끝입니다 — 서비스는 그동안 계속 실행되며, 모든
   설정은 그대로 유지됩니다.

## 알림 끄기

업데이트 알림을 보고 싶지 않다면 **설정 → 일반 → 업데이트 알림**을 끄세요. 그래도
언제든지 **업데이트 확인** 버튼으로 직접 확인할 수 있습니다.

> **업데이트가 수동인 이유:** 이렇게 하면 macOS, Windows, Linux에서 Ensembler를
> 단순하고 일관되게 유지할 수 있으며, 앱이 여러분 모르게 스스로 바뀌는 일이
> 없습니다. 미디어 파일은 업데이트로 인해 절대 영향을 받지 않습니다.
