# 서비스 관리

모든 것은 **대시보드**에서 이루어집니다. 각 서비스에는 상태와 취할 수 있는 작업을
보여주는 카드가 있습니다.

## 서비스 카드

- 색깔이 있는 **상태 점**이 한눈에 상태를 알려줍니다:
  - **녹색 — 실행 중**
  - **회색 — 중지됨**
  - **황색 — 설정 필요** 또는 **확인 필요**
- **열기**는 서비스를 **Ensembler 안에서 탭으로** 엽니다 — 별도의 브라우저 없이,
  "Not Secure" 경고도 없이. 상단 막대에서 **대시보드**와 열려 있는 서비스 사이를
  전환하고, **✕**로 탭을 닫을 수 있습니다. 현재 서비스에 대한 **새로 고침** 버튼과
  **브라우저에서 열기** 버튼도 있습니다.
- 실행 중인 각 카드에는 작은 **버전**이 표시됩니다. **🔒 자물쇠**는 서비스가 특정
  버전에 고정되었음을 뜻하고, **↻** 표시는 최신 버전을 추적한다는 의미입니다.
  업데이트가 있으면 황색으로 바뀝니다.
- **⋯ 메뉴**에 나머지 작업이 들어 있습니다: **브라우저에서 열기**,
  **시작 / 중지**, **다시 시작**, **로그 보기**, **업데이트 확인**, **구성**.

서비스가 시작되거나 중지되는 동안에는 상태에 잠깐 "시작하는 중…/중지하는 중…"이
표시되어 무언가 진행되고 있음을 알 수 있습니다.

## 서비스 추가 및 제거

- **서비스 추가**(서비스 섹션 상단)로 설정 중에 선택하지 않은 것을 무엇이든 추가할
  수 있으며, 찾기 쉽도록 카테고리별로 묶여 있습니다.
- 서비스를 제거하려면 해당 서비스의 **⋯ 메뉴 → 구성**을 여세요.

여기서도 대시보드에서도 서비스는 카테고리별로(미디어 서버, 미디어 관리, 다운로드
클라이언트 등) 묶여 있습니다.

## 서비스 최신 상태 유지

- Ensembler가 백그라운드에서 조용히 확인하므로, 사용 가능한 업데이트가 저절로
  나타납니다. **업데이트 확인**(서비스 섹션 상단)을 클릭하여 지금 전부 확인하거나,
  서비스의 **⋯ 메뉴 → 업데이트 확인**으로 하나씩 확인할 수도 있습니다(결과는
  카드에 표시됩니다).
- 업데이트가 있으면 서비스 헤더에 개수가 표시되고, **전체 업데이트** 버튼으로 한
  번에 적용합니다. 하나만 업데이트하려면 카드의 **업데이트 있음 — 지금 업데이트**를
  클릭하세요. 설정은 유지됩니다.
- **버전 고정.** 기본적으로 각 서비스는 최신 버전을 추적합니다. 특정 버전에
  고정하려면 **⋯ 메뉴 → 구성**을 열고 **버전** 드롭다운에서 선택하세요. 고정된
  서비스는 🔒을 표시하고 업데이트를 더 이상 제안하지 않습니다.
- **자동 업데이트.** **설정 → 일반 → 업데이트 자동 설치**를 켜면 Ensembler가 사용
  가능한 업데이트를 백그라운드에서 적용합니다. 기본값은 꺼짐이므로 제어권은
  여러분에게 있습니다.

## 설정

앱 전체 옵션을 보려면 **설정**(오른쪽 상단)을 여세요. 다음 섹션으로 구성되어
있습니다:

- **외관** — 테마(밝게, 어둡게, 시스템)와 언어.
- **일반** — 창을 닫을 때 Ensembler를 메뉴 막대 / 시스템 트레이에 유지(기본값은
  켜짐; 어느 쪽이든 서비스는 계속 실행됩니다 — 완전히 종료하려면 트레이 메뉴의
  **종료**를 사용), 서비스 업데이트 자동 설치(기본값은 꺼짐), 시간대.
- **고급** — 평소에는 필요하지 않은 기술적 세부 정보: 진단(Docker 실행 여부, 몇
  개의 서비스가 켜져 있는지), 여유 디스크와 메모리, 파일 권한에 사용되는 사용자/그룹
  ID.
- **초기화 → 전체 초기화** — 모든 서비스와 그 설정을 중지 및 제거하고 Ensembler를
  새로 설치한 상태로 되돌립니다. **미디어 파일은 절대 건드리지 않습니다** — 서비스와
  그 구성만 제거됩니다.

## 설정이 저장되는 위치

Ensembler는 구성을 사용자별 숨김 폴더에 저장합니다(자동으로 관리되므로 편집할 필요는
없습니다):

- **macOS:** `~/Library/Application Support/Ensembler`
- **Windows:** `%APPDATA%\Ensembler`
- **Linux:** `~/.config/Ensembler`

**미디어 파일**(TV, 영화, 다운로드)은 설정 중에 선택한 위치에 있으며 이와는
별개입니다.

## 진단

기술적 상태 — Docker 실행 여부, 몇 개의 서비스가 켜져 있는지, 얼마나 많은 디스크와
메모리가 남아 있는지 — 는 **설정 → 고급** 아래에 있습니다. 평소에는 필요하지
않지만, 문제를 해결할 때 유용합니다.
