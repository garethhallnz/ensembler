# Ensembler란?

Ensembler는 여러분을 위해 **홈 미디어 센터**를 설정하고 실행합니다 — 인기 있는
"*arr" 스택(Sonarr, Radarr, Prowlarr 등)과 Plex나 Jellyfin 같은 미디어 서버까지 —
Docker, YAML, 명령줄을 몰라도 됩니다.

원하는 서비스를 고르면 Ensembler가 설치하고, 시작하고, 서로 연결한 뒤, 모든 것을
관리할 수 있는 단일 대시보드를 제공합니다.

## 작동 방식

내부적으로 각 서비스는 자체 **Docker 컨테이너**에서 실행됩니다. Ensembler가 Docker
구성을 생성하고, 컨테이너를 시작하고, 서로 연결하여 하나의 시스템처럼 작동하게
합니다. 구성 파일을 직접 건드릴 필요가 전혀 없습니다.

일반적인 흐름은 다음과 같습니다:

1. **설정 마법사** — 서비스를 선택하고, Ensembler에 미디어 폴더를 지정한 뒤,
   **적용**을 클릭합니다. 포트는 자동으로 확인되며, 기본 포트가 사용 중이면
   사용 가능한 포트가 자동으로 선택됩니다.
2. **자동 연결** — Sonarr와 Radarr는 다운로드 클라이언트와 폴더를 받고, Prowlarr가
   이들에 연결되며, 로그인하면 Plex가 가져오기 알림을 받는 식으로 진행됩니다. 각
   단계가 완료되는 것을 지켜볼 수 있습니다.
3. **대시보드** — 그 이후로는 한 곳에서 모든 것을 관리합니다: 서비스를 열고,
   시작/중지하고, 업데이트를 확인하거나, 서비스를 더 추가할 수 있습니다.

## 각 서비스의 역할

| 서비스 | 역할 |
|---|---|
| **Sonarr** | TV 프로그램을 관리합니다 |
| **Radarr** | 영화를 관리합니다 |
| **Bazarr** | Sonarr/Radarr의 자막을 관리합니다 |
| **Plex / Jellyfin / Emby** | 미디어를 기기로 스트리밍합니다 |
| **Transmission / Deluge** | 다운로드 클라이언트 |
| **Prowlarr / Jackett** | 서비스가 콘텐츠를 검색하는 위치를 관리합니다 |
| **Overseerr** | 미디어를 요청하고 탐색합니다 |

## Ensembler가 하는 일 — 그리고 하지 않는 일

Ensembler는 **서비스를 서로 연결합니다**. 어떤 콘텐츠도 선택, 요청,
다운로드하지 **않으며**, 인덱서나 트래커를 대신 구성하지 **않습니다**. 소스는
직접 선택하며, 그 사용 방식에 대한 책임은 여러분에게 있습니다.
