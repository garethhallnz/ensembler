# 시작하기

## 필요한 것

Ensembler는 서비스를 Docker에서 실행하므로, `docker`와 `docker compose` 명령을
제공하는 **컨테이너 런타임**이 설치되어 실행 중이어야 합니다.

- **추천 (가장 쉬움):**
  [Docker Desktop](https://www.docker.com/products/docker-desktop/) — macOS,
  Windows, Linux용 원클릭 설치. 없다면 Ensembler가 첫 실행 시 안내해 줍니다.
- **이미 다른 것을 사용 중인가요?** Docker와 호환되는 런타임이라면 무엇이든 똑같이
  잘 작동합니다 — 예를 들어 **OrbStack**(macOS), **Podman**, **Rancher Desktop**,
  **colima**, 또는 Linux의 **Docker Engine**. `docker`와 `docker compose`가
  작동하기만 하면 Ensembler가 이를 사용합니다.

앱을 사용하는 데 Node.js, 터미널, 또는 개발자 도구는 필요하지 **않습니다**.

## 첫 실행

Ensembler를 처음 열면 Docker가 실행 중인지 확인합니다. Docker가 설치되지 않았거나
시작되지 않았다면 이를 해결하는 방법이 표시됩니다 — Docker Desktop을 시작하고,
실행 중이라고 표시될 때까지 기다리면 Ensembler가 계속 진행됩니다.

## 설정 마법사

### 1. 서비스 선택
완전한 미디어 센터를 위해 추천 서비스가 미리 선택되어 있습니다. 일부 카테고리 —
다운로드 클라이언트, 인덱서 관리자, 요청 — 는 하나의 옵션만 선택할 수 있고, 다른
카테고리 — **미디어 서버**와 **미디어 관리** — 는 여러 개를 선택할 수 있습니다
(예를 들어 Plex와 Jellyfin을 함께 실행).

### 2. 폴더 설정
Ensembler에 **TV 프로그램**, **영화**, **다운로드**가 어디에 있는지 알려주세요.
이는 여러분 자신의 폴더입니다 — 라이브러리에 충분한 공간이 있는 위치를 선택하세요.
포트는 자동으로 확인되며, 기본 포트가 이미 사용 중이면 Ensembler가 조용히 사용
가능한 포트를 선택해 줍니다.

### 3. 적용
Ensembler가 구성을 생성하고, 서비스를 시작하고, 서로 연결합니다. 각 단계가
완료되는 것을 볼 수 있습니다.

## 설정 마무리

일부 단계는 여러분만 할 수 있으며, 대시보드가 **"설정 마무리"** 목록에서 이를
안내합니다:

- **Prowlarr에서 인덱서 추가** — Sonarr와 Radarr가 콘텐츠를 검색할 수 있도록
  합니다. 소스는 직접 선택하며, Ensembler가 대신 선택하지 않습니다.
- **Plex에 로그인** — 그러면 Ensembler가 TV 및 영화 라이브러리를 자동으로
  생성합니다.
- **Overseerr 마무리** — Plex로 로그인하고 다른 서비스를 검색합니다.

각 안내에는 알맞은 위치로 바로 이동하는 **열기** 링크가 있습니다.

**Jellyfin이나 Emby?** 이들은 목록에 없습니다 — Ensembler가 컨테이너를 실행하지만,
각각 자체 첫 실행 과정을 관리합니다. 대시보드에서 열고 각자의 웹 인터페이스에서
설정을 완료하세요 (관리자 계정을 만들고 라이브러리를 추가).

이 과정이 끝나면 사용할 준비가 완료됩니다.
